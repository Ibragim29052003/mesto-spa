# Место SPA

Адаптивный лендинг вымышленной SPA-студии в Москве. Тестовое задание: сравнить три программы, выбрать подходящую и сохранить демонстрационную заявку в браузере.

**Демо:** публикация ожидает подтверждения владельца. Публичная ссылка будет добавлена после размещения и проверки сайта.

## Возможности

- Три программы: «Перезагрузка» — 60 минут / 3 500 ₽; «Глубокий отдых» — 90 минут / 5 000 ₽; «Для двоих» — 120 минут / 9 000 ₽ за двоих.
- Выбор карточки подставляет программу в форму. Кастомный селект поддерживает клавиатуру и поиск по первым буквам.
- Имя, программа и локальная календарная дата: понятные ошибки рядом с полями, сегодня и будущие дни допустимы.
- Календарь с клавиатурной навигацией, возвратом фокуса и блокировкой фоновой прокрутки. На сенсорном устройстве используется системный picker при поддержке, иначе — кастомный календарь.
- Подтверждение с деталями; последняя заявка восстанавливается после обновления, её можно изменить или удалить.
- Обработка повреждённых данных и отказов localStorage без ложного сообщения об успехе.
- Адаптивная компоновка, видимый фокус, подписи и ошибки для вспомогательных технологий, reduced motion.

## Технологии

React 19, строгий TypeScript, Vite, обычный CSS с переменными. В runtime только React и React DOM. ESLint, Vitest, Playwright и axe-core используются для проверки.

Изображение локальное: два WebP-размера и srcset. Шрифты системные — Arial/Georgia, дополнительных запросов нет. Происхождение изображения описано в [ASSETS.md](ASSETS.md).

## Локальный запуск

Рекомендуется Node.js 24 LTS (версия указана в `.nvmrc`) и npm. Зависимости зафиксированы в `package-lock.json`.

```sh
npm ci
npm run dev
```

Откройте адрес из вывода Vite, обычно `http://127.0.0.1:5173/`. Переменные окружения, ключи и backend не нужны.

## Проверки

```sh
npm run typecheck
npm run lint
npm test
npm run build
npm run test:e2e
```

E2E используют установленный Google Chrome (`channel: 'chrome'`). При его отсутствии установите Chrome, например командой `npx playwright install chrome`. Затем выполните команды выше. E2E сами запускают локальный preview на порту 4173; production-сборка должна быть готова заранее.

Для просмотра production-сборки отдельно выполните `npm run preview`. Для просмотра браузерного отчёта — `npx playwright show-report`. Генерируемые отчёты, скриншоты и сборка исключены из Git.

Последний комплексный аудит: **35 unit и 44 E2E**, TypeScript/lint/build успешны. Локальный Lighthouse: Performance 98 mobile / 100 desktop; остальные три категории — 100. Это лабораторные результаты, а не измерения публичного сайта.

- [AUDIT_REPORT.md](AUDIT_REPORT.md) — результаты и границы комплексной проверки.
- [AI_WORK_LOG.md](AI_WORK_LOG.md) — реальная история разработки с OpenAI Codex и правок по обратной связи.
- [QA_REPORT.md](QA_REPORT.md) — история предыдущих прогонов.

Реальные телефоны, полная Safari/Firefox-матрица и озвучивание настоящими скринридерами отдельно не проверялись. Автоматический axe не доказывает полное соответствие WCAG.

## Структура

- `src/App.tsx` — страница, форма и подтверждение.
- `src/booking.ts` — программы, валидация, локальная дата и хранилище.
- `src/ProgramSelect.tsx`, `src/DateField.tsx`, `src/calendar.ts` — элементы выбора и календарные вычисления.
- `src/styles.css`, `src/controls.css` — оформление и адаптивность.
- `public/` — локальные изображения, favicon и robots.txt.
- `tests/` — модульные и браузерные тесты.

## Размещение

Подготовлен Netlify: `netlify.toml` задаёт `npm run build` и каталог `dist`, `.nvmrc` — Node.js 24. Нужен только статический HTTPS-хостинг; серверные функции и обработка форм Netlify не используются.

Пошаговая инструкция и список проверок публичной версии — [DEPLOYMENT.md](DEPLOYMENT.md). До подтверждения владельца репозиторий и сайт не публикуются.

## Демонстрационный характер

Студия и изображённое пространство вымышлены. Это учебный проект: backend, CRM, авторизации, платежей и настоящей записи нет. Используйте вымышленные имена.

Заявка не отправляется в студию. React безопасно отображает введённый текст; в localStorage хранятся только версия формата, имя, ID программы и дата. Аналитики и внешних запросов приложения нет.

Сохраняется одна последняя заявка в текущем браузере и на текущем домене. Очистка данных сайта удаляет её; другой профиль, устройство или приватный сеанс не видит прежнюю заявку. Синхронизация вкладок и сохранение незавершённого черновика не реализованы. Для работы нужен JavaScript.
